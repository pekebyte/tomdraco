# Project style lock

- Surface: artist portfolio, experience-led editorial long scroll.
- Colors: near-black #090909, warm white #f0ece4, red #ff2020, muted text #b6b1aa.
- Typography: VT323 for project display, Syncopate for structural headings, Barlow Condensed for reading, Share Tech Mono for navigation and metadata.
- Assets: existing artist photography and linked film thumbnails. Preserve project-specific credits.
- Motion: brief glitch on the artist name, restrained image reveals and interaction feedback. Respect reduced motion.
- Navigation: fixed top bar and full-screen mobile dialog, with keyboard dismissal and a visible close control.
- Direction: sound, image and project narratives lead; typography and red accents provide continuity.
