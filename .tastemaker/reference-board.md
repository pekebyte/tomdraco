# Reference board

Mode: Experience. An audiovisual artist portfolio for collaborators and listeners; dark editorial typography, restrained density, expressive motion and direct access to the work.

Retrieved 2026-11-11: [Disektor](https://disektor.com/work/) presents a working record organized by project type, while [Ed Davenport](https://eddavenport.com/) leads with the artist's roles and an index of individual works. Both reinforce clear paths to projects and contact. [Allan Castellanos](https://www.allancastellanos.com/) was fetched but exposed no readable page content, so its visual design was not assessed.

Direction: preserve Tom Draco's black, red, pixel lettering, photography and project narratives. Make navigation persist and give mobile visitors an uncluttered, full-screen index. Avoid making motion or navigation compete with the work.
